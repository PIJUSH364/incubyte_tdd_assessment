# String Calculator

This project is a solution to the Incubyte TDD assessment, focusing on the String Calculator . It demonstrates the practice of Test-Driven Development (TDD) using JavaScript and Jest.

## Project Structure

- `strCalculator.js`: Contains the implementation of the `add` function.
- `strCalculator.test.js`: Contains the test cases for the `add` function.
- `package.json`: Manages dependencies and scripts.


## Requirements

- The `add` function accepts a string of numbers separated by commas or new lines and returns their sum.
- It supports custom delimiters.
- It throws an exception for negative numbers, listing all negative values.
- Handles various edge cases as per the TDD Kata requirements.
